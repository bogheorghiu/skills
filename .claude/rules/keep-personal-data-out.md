# Keep personal data out of the repository, every branch and every commit

(No `paths:` on purpose: any edit can carry personal data, so this loads in every session.)

The repository is public, and a name committed once stays in its history after the file is fixed. So nothing personal is committed, not even for a moment: no real names (the owner's included), email addresses, host or trader details, review authors, or anything that identifies a traveller; no tokens or cookies.

Demo data follows the skill's own `drop` lists: listing names, public prices, coordinates and public URLs, nothing about the people behind them. Scraped output and actor logs stay out of the repository; cite a run by its ID instead.

If personal data does reach a commit, stop and tell the owner. Scrubbing history is their decision, not a side task.
